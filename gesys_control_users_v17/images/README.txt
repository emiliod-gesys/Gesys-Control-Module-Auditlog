Screenshots for Odoo Apps Store
==============================

Place your PNG, GIF or JPEG files here. Odoo uses the first image whose name
ends with "_screenshot" as the large preview on the app page.

Suggested files (2 per menu, as agreed):

  main_screenshot.png     <- Main large image (e.g. Control menu or User Actions list)
  user_actions_1.png      <- User Actions (e.g. list view)
  user_actions_2.png      <- User Actions (e.g. form view or filters)
  actions_by_employee_1.png
  actions_by_employee_2.png
  change_lines_1.png
  change_lines_2.png
  user_activity_1.png     <- User Activity dashboard
  user_activity_2.png
  statistics_1.png        <- Statistics dashboard
  statistics_2.png
  rules_1.png
  rules_2.png
  configuration_1.png
  configuration_2.png

You can add fewer files; if so, remove or comment the unused entries from
the 'images' list in __manifest__.py.
