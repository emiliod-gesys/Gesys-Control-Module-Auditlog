Control – User Activity Audit & Insights

Control records and monitors key user actions in your Odoo database. It provides an audit trail for validations, invoices, payments and cancellations, with dashboards, statistics, and optional automatic cleanup.

Features

  • Action logging – Tracks key actions such as validate, post, cancel, export, print, email and import, plus supported model operations.
  • Change lines – Stores field-level changes (old/new values) for write operations when enabled.
  • Views – List of all actions, actions grouped by employee, and filter by date and type.
  • Activity dashboard – Visual overview of recent user activity.
  • Statistics dashboard – Charts and aggregates by period (hour, day, week, month).
  • Reports – PDF reports (activity summary, executive summary, by user) and Excel export for statistics.
  • Rules (per model) – Exclude specific users or fields from supported tracking flows; managed by administrators.
  • Configuration – Timezone, language (English/Spanish), optional read logging, and log mode (full vs. minimal).
  • Automatic purge – Scheduled job to delete old action records after a configurable retention period.
  • Security – Two groups: User (view logs and dashboards) and Manager (configuration and rules).

Requirements

  • Odoo 17.0
  • Dependencies: base, mail, account, web, sale, purchase
  • Python: xlsxwriter (for Excel export)

Installation

  1. Install the module from the Odoo Apps menu or by placing it in your addons path and updating the app list.
  2. Assign users to the Control / User or Control / Administrator group as needed.
  3. Configure options (timezone, retention, rules) via Control → Configuration (Manager only).

Usage

After installation, go to the Control app. Use User Actions to browse the full log, Actions by Employee to group by user, User Activity and Statistics for dashboards, and Rules to exclude models/users/fields from logging. Use Configuration to set retention, timezone, and language.
